# 🚀 Space Shooter

A polished 2D pixel-art arcade shooter built with **Python** and **Pygame**.

## Features

- 🚀 Smooth player movement
- 🔫 Multiple weapon types
  - Normal Shot
  - Rapid Fire
  - Double Shot
- 🛡 Shield Power-up
- ❤️ Health Power-up
- 👾 Five enemy types
  - Normal
  - Fast
  - Carrier (Splits into two enemies)
  - Zigzag
  - Shooter
- 🤖 Progressive Boss System
- 💥 Screen Shake
- 🎵 Background Music & Sound Effects
- 🏆 High Score Saving
- 🖥 Fullscreen Support
- ⏸ Pause Menu

## Technologies Used

- Python 3.11
- Pygame 2.6.1

## Controls

| Key | Action |
|------|--------|
| A / Left Arrow | Move Left |
| D / Right Arrow | Move Right |
| W / Up Arrow | Move Up |
| S / Down Arrow | Move Down |
| Space | Shoot |
| Esc | Pause |
| F11 | Toggle Fullscreen |

## Installation

```bash
pip install -r requirements.txt
python main.py
```
